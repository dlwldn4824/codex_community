# VibeCheck 결선 제출 요약

VibeCheck는 바이브 코딩으로 만든 서비스의 코드 구조를 **서비스 기능과 데이터·권한 흐름**으로 바꾸어 보여주는 보안 검증 도구입니다. 파일 목록이나 점수보다, 어디에서 어떤 정보가 이동하고 어떤 연결을 확인해야 하는지 먼저 보여줍니다.

## 실제 구현 범위

- 공개 GitHub 저장소의 읽기 전용 clone과 구조 분석
- Semgrep 기반 정적 분석
- 기능·데이터·권한 흐름 기반 보안 지도
- 회사 보안 정책 문서 업로드와 문단 검색
- 승인된 로컬 대상에서의 HTTP 증거 → 규칙 판정 → 사람 승인 → 패치 → 동일 요청 재검증
- `OPENAI_API_KEY`가 설정된 경우 Codex API로 한 파일 단위 수정안을 생성하고, 새 로컬 복제본에서만 적용 가능 여부를 확인

## 현재 제한 사항

- 원격 GitHub 저장소에는 코드를 수정하거나 push하지 않습니다.
- 임의의 외부 서비스에는 공격 요청을 보내지 않습니다.
- 외부 저장소의 빌드·테스트는 격리 실행 환경을 갖춘 경우에만 실행해야 하며, 현재는 실행하지 않은 경우 결과에 명시합니다.
- Codex API 수정안은 API 사용 한도와 계정 설정이 필요하며, 자동 적용 전 `git apply --check`로 파일 범위를 제한합니다.

## Codex 활용 방식

Codex는 결과를 임의로 만들어 내는 역할이 아니라, 사람이 정한 안전 범위 안에서 다음 업무를 수행했습니다.

1. 저장소 분석과 서비스 보안 지도 구현 계획을 세움
2. GitHub clone, Semgrep 연결, 코드 사실 추출, UI를 구현함
3. 초기 그래프가 코드 분석 순서처럼 보인다는 피드백을 반영해 기능·데이터 흐름 중심으로 재설계함
4. 화면 라우팅, 재점검 버튼, Vercel 서버리스 배포 오류를 점검하고 수정함
5. Golden Demo 테스트와 배포 응답을 확인함

개인 프롬프트나 API 키는 저장소와 제출 문서에 포함하지 않았습니다.
