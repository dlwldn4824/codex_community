# VibeCheck 핵심 사용자 흐름 데모 영상 대본

권장 길이: 90초

## 촬영 전 준비

```bash
npm start
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열고, 공개 GitHub 저장소 URL을 준비합니다.

## 0–15초: 문제

화면: VibeCheck 첫 화면

내레이션:

> AI로 서비스는 빠르게 만들 수 있습니다. 하지만 개인정보와 권한이 실제로 어디로 흐르는지, 개발자는 쉽게 확인하기 어렵습니다.

## 15–30초: 저장소 연결

화면: GitHub URL 입력 후 `연결하고 분석하기`

내레이션:

> VibeCheck에 공개 GitHub 저장소를 연결하면, 코드를 파일 목록이 아니라 서비스 기능과 정보 흐름으로 다시 읽습니다.

## 30–45초: 분석 진행

화면: 분석 진행률과 로그

내레이션:

> 프로젝트 구조, 권한 관계, 회사 정책 문서, 점검 경로를 순서대로 확인합니다. 정적 분석에는 실제 오픈소스 Semgrep을 사용합니다.

## 45–65초: 서비스 보안 지도

화면: 분석 완료 뒤 서비스 보안 지도

내레이션:

> 결과는 코드 경로나 규칙 이름만 보여주지 않습니다. 화면, 인증, API, 데이터 처리, 외부 연동을 연결해 서비스 지도로 보여줍니다. 빨간 선은 실제 코드 근거가 있어 추가 확인이 필요한 정보 또는 권한의 이동입니다.

빨간 edge를 하나 선택합니다.

> 이 선을 누르면 어떤 위험이 의심되는지, 관련 코드와 정적 분석 근거를 확인할 수 있습니다.

## 65–80초: 사람 중심 검토

화면: 확인된 위험 카드와 정책 근거

내레이션:

> VibeCheck는 “취약점 개수”로 끝내지 않습니다. 어떤 기능에서 어떤 데이터가 왜 위험할 수 있는지부터 설명하고, 회사 정책과 보안 규칙을 근거로 사람이 판단할 수 있게 합니다.

## 80–90초: 마무리

화면: 서비스 보안 지도 전체

내레이션:

> VibeCheck는 AI가 만든 코드를, 사람이 이해하고 검증할 수 있게 합니다.

## 영상에 반드시 보일 것

- GitHub URL 입력
- 분석 진행률이 단계별로 변하는 모습
- Semgrep 로그
- 기능별 노드와 edge가 있는 서비스 보안 지도
- 빨간 위험 edge의 자연어 설명
- 현재 MVP가 외부 서비스에 공격 요청을 보내지 않는다는 안전 범위
