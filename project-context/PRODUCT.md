# VibeCheck 제품 정의

VibeCheck는 바이브 코딩으로 만든 앱을 대상으로 **실제 공격을 실행하고**, 그 결과를 NeSy 규칙으로 검증한 뒤, 사람이 승인한 수정만 적용하고 같은 공격을 재실행해 방어를 증명하는 보안 하네스입니다.

## 현재 Golden Demo

- 범위: `localhost`의 데모 대상만 테스트
- 공격: `member01`이 `GET /api/users/2` 실행
- 정책: `MEMBER`는 다른 사용자의 프로필을 읽을 수 없음 (`BAC-001`)
- 전: 실제 HTTP `200` → 위반
- 사람 승인 뒤: 서버 코드에 소유권 검사 추가
- 후: 동일 실제 HTTP `403` → 통과
